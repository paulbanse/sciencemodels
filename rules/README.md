# rules/

Governance policy for this project: the sole home of normative rules (per the
authority split in ADR-0001, proposed). A policy outside `rules/` does not
bind. Files are MO-docs; naming: `<topic>.md`. `IDEA.md` (repository root) is
authoritative.

- `multiagent-coordination.md` - how several humans and AI agents share this
  repository and its records.
- `coding-style.md` - code organisation, the notebooks-vs-scripts division,
  reproducibility rules.

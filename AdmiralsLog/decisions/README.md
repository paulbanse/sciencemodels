# decisions/

Proposed, undecided ADRs live at this top level with `Status: proposed`.
Ruled decisions move to `accepted/` or `rejected/` (both binding), keeping
their ids. Naming: `ADR-####-<slug>.md`. `IDEA.md` (repository root) is
authoritative.

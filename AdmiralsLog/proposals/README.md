# proposals/

Suggestions of all sorts awaiting the owner's ruling: **operative** proposals
(a route for something the project already wants) and **strategic** proposals
(a direction or framing choice). Status runs `open` -> `exercised` ->
`adopted`/`dismissed`. Nothing here binds; an adopted proposal that binds
behaviour spawns an ADR, which cites the proposal in `Spawned:`. Naming:
`P-####-<slug>.md`. `IDEA.md` (repository root) is authoritative.
